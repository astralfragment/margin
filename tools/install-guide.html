Install and update Margin

Version {{version}}. Margin runs in Chrome or Edge from a folder on your computer. Everything you capture stays on this computer until you send it to Jira or Figma.

Install

  1. Unzip this file into a folder you will keep, such as Documents. Chrome loads Margin from that folder every time it starts, so do not delete it.
  2. In Chrome, open chrome://extensions. In Edge, open edge://extensions.
  3. Turn on Developer mode. It is at the top right in Chrome and on the left in Edge.
  4. Click Load unpacked and choose the Margin folder, the one with manifest.json inside.
  5. Pin Margin from the puzzle piece in the toolbar. The welcome tour opens in a new tab.

Update to a new version

  1. Unzip the new version.
  2. Replace everything inside your existing Margin folder with the contents of the new Margin folder.
  3. On the extensions page, click the reload arrow on the Margin card.
  4. Check the version on the card, or at the top of Help and settings in Margin. Your reviews and screenshots stay.

Never click Remove to update. Removing Margin deletes every review and screenshot it holds.

Coming from a build before 0.2.0

Earlier builds were a separate install, so this version starts empty. Before you remove the old one, open its report and download each review as a Word or HTML file. Then remove the old Margin card and install this version.

Chrome Web Store version

Once Margin is in the Chrome Web Store, install it from the link the team shares and it updates itself. It is a separate install from this folder, so export your reviews here first, then remove this copy.

If something goes wrong

Manifest file is missing
You picked the outer folder. Choose the Margin folder that has manifest.json directly inside.
Developer mode warning
Chrome reminds you about folder installs now and then. Close the message, Margin keeps working.
Nothing happens on a page
Chrome blocks extensions on its own pages, the Web Store and the new tab page. Try a normal website.
The shortcut does nothing
Set or change it at chrome://extensions/shortcuts.
Reviews are gone
Check the ID on the Margin card reads {{id}}. A different ID means an older build or a second install.

Remove Margin

Download any review you want to keep as a Word or HTML file first. Then click Remove on the Margin card and delete the folder.
